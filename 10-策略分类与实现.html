策略分类与实现：四大家族，逐行精讲

目标：搞清策略有哪些流派 → 每个流派适合什么行情、为什么有效、会在什么情况下亏钱 → 各自给出可跑的完整代码（逐行注释）。读完你能按行情挑策略、看懂别人的策略属于哪派。名词不认识的回 09 篇 1½ 节术语表查。

1先看全景：行情只有两种，策略分四大派

所有技术面策略，本质上都在回答同一个问题——「价格接下来会怎么走？」。而答案只有两种信仰：

  • 趋势派相信：涨的会继续涨，跌的会继续跌（惯性）→ 顺势而为
  • 回归派相信：涨多了会跌回来，跌多了会弹回去（均值回归）→ 逆势抄底摸顶

再加上「入场方式」的差别（跟随已形成的趋势 / 赌突破关键位 / 追逐涨速），就展开了四大流派：

流派一句话原理适合行情怕什么行情代表指标
① 趋势跟随趋势已形成，顺着方向上车单边趋势市震荡市（反复打脸）EMA、MACD、ADX
② 均值回归价格偏离均值太远，赌它弹回去区间震荡市单边暴跌（接飞刀）布林带、RSI、KDJ
③ 突破横盘被打破的瞬间跟进，赌大行情启动长期盘整→变盘假突破（追高被套）唐奇安通道、箱体高低点
④ 动量最近涨得猛的会继续猛（强者恒强）普涨牛市急速反转ROC、涨跌幅排名
图 10-1 · 同一段走势，趋势派与回归派的视角对比：策略亏损大多源于「流派与行情错配」
⚠️ 先记住这个不等式

策略的亏损，大部分不是代码写得差，而是「用错行情」。趋势策略在震荡市里被反复止损，回归策略在单边市里越抄越跌——这不是 bug，是流派天性。所以每节开头都写清「适合什么、怕什么」。

2家族一：趋势跟随（Trend Following）

2.1 原理与适用场景

核心信仰：价格有惯性，已形成的趋势大概率延续一段。做法：用两条快慢均线判断方向，方向一致时入场，方向反转时离场。牺牲胜率换盈亏比——典型趋势策略胜率只有 35-45%，但一次大趋势的利润能覆盖多次小亏损。

维度说明
适合行情单边趋势市：BTC 牛市主升浪、暴跌后的持续阴跌
怕什么无趋势的箱体震荡：均线反复金叉死叉，每次都是小亏，积累起来很致命
盈利结构低胜率（35-45%）+ 高盈亏比（赚一笔顶亏三四笔）
典型改进加 ADX 强度过滤（震荡市不交易）、用追踪止损让利润奔跑

2.2 完整代码（EMA 交叉 + ADX 过滤，逐行注释）

user_data/strategies/TrendFollowStrategy.py
from pandas import DataFrame          # DataFrame = 装K线的表格（每行一根K线）
import talib.abstract as ta             # 技术指标计算库
from freqtrade.strategy import IStrategy, IntParameter
                                      # IStrategy = 策略基类；IntParameter = 可被 hyperopt 优化的整数参数


class TrendFollowStrategy(IStrategy):  # 策略类，继承基类；类名必须与 --strategy 参数一致

    INTERFACE_VERSION = 3               # 声明用 v3 现代接口（enter_long/exit_long 四列协议）

    # ---------- 引擎行为 ----------
    timeframe = '1h'                  # 1小时K线。趋势策略用大周期，噪音少、信号稳
    can_short = False                # 现货只做多
    startup_candle_count = 260         # 预热K线数：EMA200(200) + ADX(14) + 裕量 → 260 根
    process_only_new_candles = True    # 只在新K线收盘时计算（信号确定，省 CPU）

    # ---------- 退出规则 ----------
    minimal_roi = {                    # 趋势策略**不要**用紧的 ROI 止盈——会把大利润截断！
        '0': 0.30,                  # 设一个很宽的 +30%：正常情况下永远轮不到它触发，
    }                                  # 利润主要靠 exit 信号（趋势反转）和追踪止损去吃
    stoploss = -0.10                 # 硬止损 -10%：趋势策略止损要宽（容得回撤），否则被震出局
    trailing_stop = True              # 开追踪止损：趋势走多远，利润就跟多远（趋势策略灵魂）
    trailing_stop_positive = 0.03     # 从最高点回撤 3% 就平仓锁利
    trailing_stop_positive_offset = 0.06
                                      # 浮盈达 +6% 才激活追踪（刚开仓仍受 -10% 硬止损保护）
    trailing_only_offset_is_reached = True
                                      # 未到 +6% 前不追踪，两个机制分段接力

    # ---------- 可优化参数 ----------
    adx_threshold = IntParameter(15, 35, default=25, space='buy')
                                      # ADX 强度门槛：hyperopt 在 15~35 之间找最优值，默认 25

    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 第 1 步：算指标（只加列，不做决策）。metadata['pair'] = 当前币名
        dataframe['ema_fast'] = ta.EMA(dataframe, timeperiod=20)
                                      # 20周期快线：最近 20 根K线收盘价的加权平均，反应快
        dataframe['ema_slow'] = ta.EMA(dataframe, timeperiod=200)
                                      # 200周期慢线：长期趋势的「水位线」
        dataframe['adx'] = ta.ADX(dataframe, timeperiod=14)
                                      # ADX(平均趋向指数)：衡量趋势**有多强**（0~100）。
                                      # >25 = 强趋势；<20 = 没趋势（震荡）。注意它不看方向，只看强度
        return dataframe

    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 第 2 步：填入场信号。三个条件全部满足才买：
        dataframe.loc[
            (dataframe['ema_fast'] > dataframe['ema_slow']) &
                                      # 条件1：快线在慢线上方 → 大方向向上（趋势存在）
            (dataframe['adx'] > self.adx_threshold.value) &
                                      # 条件2：ADX > 25 → 这不是震荡，是真趋势（本策略的灵魂过滤）
            (dataframe['volume'] > 0),         # 条件3：这根K线有成交（排除异常数据）
            'enter_long'                   # 写入 v3 入场信号列
        ] = 1                           # 满足的行 = 1 = 买入
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 第 3 步：填离场信号。趋势反转（快线跌回慢线下方）就撤：
        dataframe.loc[
            (dataframe['ema_fast'] < dataframe['ema_slow']),
                                      # 快线死叉慢线 → 上升趋势结束，不猜测、不扛单
            'exit_long'
        ] = 1
        return dataframe
✅ 趋势策略三条军规
  1. 止损要宽（-8% ~ -12%）：趋势启动前常有回踩，窄止损会被扫出局。
  2. 别用紧 ROI 止盈：趋势的钱在一两次大行情里，+3% 就跑等于放弃盈亏比。
  3. 必须有趋势强度过滤（ADX/ATR）：纯均线交叉在震荡市是绞肉机。

3家族二：均值回归（Mean Reversion）

3.1 原理与适用场景

核心信仰：价格围绕价值上下波动，偏离太远会被「拉回来」。做法：用布林带标出「正常波动范围」，价格跌出下轨（超卖）时买入，弹回中轨时卖出。高胜率 + 小盈利——赚很多次小钱，怕一次大亏。

维度说明
适合行情区间震荡市：价格在一个箱体内来回（主流币大部分时间处于此状态）
怕什么单边暴跌：跌出下轨不代表会弹回，可能是崩盘开始——「接飞刀」。所以必须带硬止损
盈利结构高胜率（55-70%）+ 低盈亏比（每笔赚 1-3%，止损 5%）
与趋势派对比互为镜像：趋势派低胜率高盈亏比，回归派高胜率低盈亏比

3.2 完整代码（布林带 + RSI 双确认，逐行注释）

from pandas import DataFrame
import talib.abstract as ta
from freqtrade.strategy import IStrategy, IntParameter


class MeanReversionStrategy(IStrategy):
    """跌出布林下轨 + RSI 超卖 → 买；弹回中轨 → 卖"""

    INTERFACE_VERSION = 3

    # ---------- 引擎行为 ----------
    timeframe = '15m'                 # 回归策略用中小周期：震荡的机会更多、更快
    can_short = False
    startup_candle_count = 120         # 布林(20) 和 RSI(14) 都很短，120 根绰绰有余
    process_only_new_candles = True

    # ---------- 退出规则 ----------
    minimal_roi = {
        '0': 0.04,                  # +4% 止盈：回归策略的目标就是回到均值，别贪
        '120': 0.02,                 # 2小时后降为 +2%：久等不弹说明判断错了，降低期待
    }
    stoploss = -0.05                 # 硬止损 -5%：**回归策略的生命线**。
                                      # 它怕的就是单边暴跌，止损是唯一的防弹衣
    # 注意：回归策略不用追踪止损——利润目标本来就是小反弹，
    # 追踪止损会把还没走完的反弹提前掐掉

    # ---------- 可优化参数 ----------
    rsi_buy = IntParameter(20, 40, default=30, space='buy')
                                      # RSI 入场阈值，默认 30（经典超卖线）

    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 布林带：以 20周期均线为中轨，上下各 ±2 倍标准差画出通道。
        # 统计含义：约 95% 的收盘价落在带内 → 跌出下轨 = 小概率事件 = 超卖
        bb = ta.BBANDS(dataframe, timeperiod=20, nbdevup=2.0, nbdevdn=2.0)
                                      # timeperiod=20 中轨周期；nbdevup/dn=2.0 上下轨宽度（2倍标准差）
                                      # 返回一个字典：上轨/中轨/下轨三条线
        dataframe['bb_upper'] = bb['upperband']   # 上轨：正常波动的天花板
        dataframe['bb_middle'] = bb['middleband'] # 中轨：20周期均线，即「均值」本尊
        dataframe['bb_lower'] = bb['lowerband']   # 下轨：正常波动的地板
        dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)
                                      # RSI：确认超卖的第二个证据（双指标确认，减少误判）
        return dataframe

    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 入场：价格砸穿地板 + RSI 确认超卖 → 赌弹回
        dataframe.loc[
            (dataframe['close'] < dataframe['bb_lower']) &
                                      # 条件1：收盘价 < 布林下轨 → 已跌出 95% 的正常范围
            (dataframe['rsi'] < self.rsi_buy.value) &
                                      # 条件2：RSI < 30 → 下跌动能也确认衰竭（防止「跌出下轨但还在加速跌」）
            (dataframe['volume'] > 0),
            'enter_long'
        ] = 1
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 离场：价格弹回中轨 = 回归完成 = 目标达成，落袋
        dataframe.loc[
            (dataframe['close'] > dataframe['bb_middle']),
                                      # 收盘价站回中轨上方。别贪到上轨——弹到中轨就开始回落是常态
            'exit_long'
        ] = 1
        return dataframe
✅ 回归策略三条军规
  1. 止损是生命线：单边市里「跌出下轨」会一低再低，没有止损的回归策略终将死于一次黑天鹅。
  2. 止盈要克制：目标就是回到中轨，+2~4% 即落袋，贪到上轨的代价是利润回吐。
  3. 双指标确认：位置（布林）+ 动能（RSI）同时超卖才进场，能砍掉一半的假信号。

4家族三：突破（Breakout）

4.1 原理与适用场景

核心信仰：长期横盘积累的能量，会在价格突破盘整区间的那一刻释放。做法：盯着近 N 天的最高价（唐奇安上轨），价格创出新高就追入，赌新趋势启动。这是传奇「海龟交易法则」的原型。

维度说明
适合行情长时间窄幅盘整后的变盘窗口（横有多长，竖有多高）
怕什么假突破：刚追入价格就跌回区间，止损出局——突破策略的主要亏损来源，胜率通常只有 30-40%
盈利结构最低胜率 + 最高盈亏比：一次真突破的利润覆盖七八次假突破
典型改进要求突破K线放量、确认收盘站稳（而非盘中触碰）、突破前波动率收缩

4.2 完整代码（唐奇安通道突破 + 放量确认，逐行注释）

user_data/strategies/BreakoutStrategy.py
from pandas import DataFrame
import talib.abstract as ta
from freqtrade.strategy import IStrategy, IntParameter


class BreakoutStrategy(IStrategy):
    """价格创 20 日新高且放量 → 追入；跌破 10 日新低 → 离场（海龟思想简化版）"""

    INTERFACE_VERSION = 3

    # ---------- 引擎行为 ----------
    timeframe = '1h'                  # 突破看关键位，用 1h 减少盘内噪音
    can_short = False
    startup_candle_count = 240         # 唐奇安窗口(20) + 成交量均线(20) + 大裕量
    process_only_new_candles = True

    # ---------- 退出规则 ----------
    minimal_roi = {                    # 同趋势策略：宽 ROI，让利润奔跑
        '0': 0.25,
    }
    stoploss = -0.08                 # 止损比趋势派略紧：假突破要快认错
    trailing_stop = True              # 真突破走成趋势后，靠追踪止损吃全程
    trailing_stop_positive = 0.03
    trailing_stop_positive_offset = 0.05
    trailing_only_offset_is_reached = True

    # ---------- 可优化参数 ----------
    vol_multiplier = IntParameter(1, 3, default=2, space='buy')
                                      # 放量倍数：突破K线成交量需是平均量的几倍

    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        dataframe['don_high'] = dataframe['high'].rolling(20).max().shift(1)
                                      # 唐奇安上轨 = 前 20 根K线的最高价。
                                      # ⚠️ .shift(1) 是关键：往前挪一根，只看「之前」的 20 根，
                                      # 不然「今天的最高价 > 含今天的 20 日最高」永远不成立
        dataframe['don_low'] = dataframe['low'].rolling(10).min().shift(1)
                                      # 唐奇安下轨 = 前 10 根的最低价（离场用短窗口，跑得快）
        dataframe['vol_avg'] = dataframe['volume'].rolling(20).mean()
                                      # 20周期平均成交量，用来判断「放量」
        return dataframe

    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 入场：收盘价突破前 20 根高点 + 成交量放大（假突破过滤）
        dataframe.loc[
            (dataframe['close'] > dataframe['don_high']) &
                                      # 条件1：收盘价 > 唐奇安上轨 → 创出 20 日新高（用收盘价
                                      # 而非最高价：要求「站稳」，过滤盘中冲高回落的假突破）
            (dataframe['volume'] > dataframe['vol_avg'] * self.vol_multiplier.value) &
                                      # 条件2：成交量 > 平均量×2 → 市场真金白银在推，不是诱多
            (dataframe['volume'] > 0),
            'enter_long'
        ] = 1
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 离场：跌破前 10 根低点 → 突破失败或趋势结束，立刻撤
        dataframe.loc[
            (dataframe['close'] < dataframe['don_low']),
            'exit_long'
        ] = 1
        return dataframe
⚠️ 突破策略的两大坑
  1. 忘写 .shift(1)：唐奇安轨道包含了「当前K线」，条件永远无法触发或产生未来函数——这是新手写突破策略的第一大 bug。
  2. 入场太早：用盘中价格触碰就买，会吃满假突破；用收盘价确认宁可少赚一点，胜率高一截。

5家族四：动量（Momentum）

5.1 原理与适用场景

核心信仰：涨得快的会继续快（强者恒强）。学术上叫动量效应，是实证金融里最扎实的异象之一。单币上用 ROC（变化率）衡量「最近涨了多少」；多币组合上则是「买涨幅榜前几名、定期换仓」——后者 freqtrade 需要自定义，本篇给单币版。

维度说明
适合行情普涨牛市：资金持续流入，强势币领涨
怕什么V 型反转：动量指标滞后，急跌时来不及反应
盈利结构中胜率 + 中盈亏比；持仓周期短（几天），换手率高、手续费敏感

5.2 完整代码（ROC 动量 + 均线方向过滤，逐行注释）

user_data/strategies/MomentumStrategy.py
from pandas import DataFrame
import talib.abstract as ta
from freqtrade.strategy import IStrategy, IntParameter, DecimalParameter
                                      # DecimalParameter = 小数型可优化参数（阈值类用它）


class MomentumStrategy(IStrategy):
    """最近 N 根K线涨幅超过阈值 + 大方向向上 → 追强势；动量转负 → 离场"""

    INTERFACE_VERSION = 3

    # ---------- 引擎行为 ----------
    timeframe = '4h'                  # 4小时：动量在日线级别最有效，但等日线太慢，4h 折中
    can_short = False
    startup_candle_count = 230         # EMA200 + ROC 窗口 + 裕量
    process_only_new_candles = True

    # ---------- 退出规则 ----------
    minimal_roi = {                    # 动量会衰竭：分批降低止盈门槛
        '0': 0.10,
        '48': 0.05,                 # 2天后（4h×12根）：+5% 也走
    }
    stoploss = -0.07                 # 动量策略反应快，止损中等偏紧
    trailing_stop = True
    trailing_stop_positive = 0.025     # 从最高点回撤 2.5% 即锁利（动量衰竭跑得快）
    trailing_stop_positive_offset = 0.04
    trailing_only_offset_is_reached = True

    # ---------- 可优化参数 ----------
    roc_threshold = DecimalParameter(0.03, 0.15, default=0.06, decimals=2, space='buy')
                                      # ROC 入场门槛：默认 6%（3%~15% 之间优化）， decimals=2 保留两位小数

    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        dataframe['roc'] = ta.ROC(dataframe, timeperiod=12)
                                      # ROC(变化率) = (今收 - 12根前收) / 12根前收。
                                      # 0.06 = 最近 48 小时涨了 6%。衡量「涨速」
        dataframe['ema_slow'] = ta.EMA(dataframe, timeperiod=200)
                                      # 大方向过滤：只在 200EMA 上方追多（牛市里做动量）
        return dataframe

    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 入场：涨速快 + 大趋势向上（动量与趋势的合体）
        dataframe.loc[
            (dataframe['roc'] > self.roc_threshold.value) &
                                      # 条件1：ROC > 6% → 最近 12 根K线涨了 6% 以上，强势
            (dataframe['close'] > dataframe['ema_slow']) &
                                      # 条件2：价格在 200EMA 上方 → 大盘环境配合，避免熊市里追反弹
            (dataframe['volume'] > 0),
            'enter_long'
        ] = 1
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 离场：动量转负 = 涨势停止，强势逻辑消失，立刻撤
        dataframe.loc[
            (dataframe['roc'] < 0),            # ROC < 0 → 最近 12 根K线整体在跌
            'exit_long'
        ] = 1
        return dataframe

家族原理一句话为何本篇不展开
网格（Grid）在区间内挂一排买卖单，跌一格买、涨一格卖，吃震荡freqtrade 原生不按网格模型设计，需大量 custom 代码；且单边行情必亏
