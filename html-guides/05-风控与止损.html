风控与止损：活得久，比赚得快重要

目标：理解「活得久比赚得快重要」。止损、仓位、回撤控制是策略的命 —— 尤其对 crypto-trader 这种趋势策略，止损就是安全气囊。本章用一张图讲透：止损太宽等于没设，太窄会被噪声反复扫出。

1止损：给预测标一个「错误上限」

止损的本质不是「亏多少割肉」，而是给策略的每次预测预设一个错误上限 —— 承认模型会错，错了只允许亏这么多。

图 5-1 · 固定止损：错了只允许亏 5%，把单笔风险锁死

2止损宽度必须和波动率匹配

这是 crypto-trader 项目踩过的最实在的一课：BTC 1h 的常见波动就超过 5%。如果你的止损比市场噪声还窄，你会被「正常晃动」反复扫出局。

图 5-2 · 止损宽窄两难：太窄被噪声扫出，太宽形同虚设，正解是 ATR 自适应

ATR 止损怎么做

ATR（平均真实波幅）止损 —— 让止损跟着波动走# 真实波幅 TR = max(high-low, |high-prev_close|, |low-prev_close|)
# ATR = TR 的 N 日均值（通常 14）
df['atr'] = df['high'].sub(df['low']) \
    .combine(df['high'].sub(df['close'].shift(1)).abs(), max) \
    .combine(df['low'].sub(df['close'].shift(1)).abs(), max) \
    .rolling(14).mean()

# freqtrade 动态止损（每根K线回调）：
def custom_stoploss(self, pair, trade, current_time, current_rate, current_profit, **kwargs):
    dataframe, _ = self.dp.ohlcv(pair, self.timeframe)
    atr = dataframe['atr'].iloc[-1]
    return -2 * atr / current_rate  # 2 倍 ATR 的动态止损比例

4仓位管理：每次买多少

方式说明特点适合
固定金额每笔同额（crypto-trader：50 USDT）简单，单笔风险可控可算起步阶段（你在这里）
固定比例按总资金百分比（如 2%）账户增长时自动加仓，复利稳定盈利后
凯利公式f* = (bp−q)/b，按胜率盈亏比求最优理论最优，实战需打对折（半凯利）进阶；赌徒全仓凯利会破产
💡 crypto-trader 的风险算术（自己算一遍）

固定 50U 仓位 × 5% 止损 = 单笔最多亏 2.5 USDT。连续亏 5 笔 = 12.5U。问题：账户本金多少？如果本金 500U，12.5U 是 2.5%，扛得住；如果本金只有 100U，5 连亏就是 12.5%，要警惕。仓位大小永远要和本金与心理承受力挂钩。

📌 判断止损合不合理的实操方法
  1. 先看标的波动率分布（ATR / 收益率的 std）—— 止损至少是它的 2-3 倍。
  2. 再跑回测，统计被止损扫掉的笔数占比：若 >40% 被止损离场，说明止损太紧或策略在震荡市乱开仓。
  3. 回测里故意把止损调宽/调窄对比，观察总收益和回撤如何权衡。

7实践任务

动手做

  1. 给同一策略配 -3% / -5% / -10% 三档止损，回测对比收益、回撤、胜率 —— 找到「最优区间」而非最优值。
  2. 统计回测中被止损的笔数占比：过高说明止损太紧或策略在震荡市乱开仓。
  3. 写一个 ATR×2 的动态止损版本，对比固定止损的表现。
  4. 算清楚 crypto-trader 的风险算术：50U × 5% = 2.5U 单笔风险；连续亏 5 笔占本金多少？

8自查清单

  • 能解释为什么 -10% 止损对 BTC 1h 太宽（波动率匹配）
  • 知道固定止损与 ATR 止损的区别与各自场景
  • 会算单笔最大亏损金额并判断其对本金的影响
  • 理解「止损被频繁触发」意味着什么（噪声/策略错）
  • 知道追踪止损如何锁住利润
