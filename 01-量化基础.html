STEP ① · 地基

量化基础：策略、数据与「回测为什么骗人」

目标：建立 「策略是什么 → 方法论 → 策略框架 → 数据与下单 → 回测验证 → 评价与陷阱」的完整认知。本章已整合聚宽《量化交易零基础入门教程》的通用知识（重编为 freqtrade 对照版，剔除全部平台操作），是后面所有步骤的地基，也是你 crypto-trader 踩坑（&-target）的理论源头。

1什么是量化交易

借助统计和数学方法，用计算机来执行交易。本质就三步：

  1. 获取数据：读取价格、成交量等行情。
  2. 制定规则：明确什么条件买、什么条件卖。
  3. 自动执行/提示：程序持续监控，条件满足就行动。

一条策略 = 一整套可被机器执行的规则。它不是「我觉得会涨」，而是四个问题的明确答案：

入场 Buy

满足什么条件开仓？
例：均线金叉 / 预测概率 > 0.6

出场 Sell

满足什么条件平仓？
例：止盈 / 信号消失 / 预测转空

仓位 Size

每次买多少？
例：固定 50 USDT / 资金 2%

风控 Risk

错了亏到哪止损？
例：-5% 固定 / ATR×2 动态

量化 = 把上面四个答案写成代码，让机器可复现地执行 —— 同一段历史数据，任何人跑同一策略，结果必须完全一致。可复现性是量化和「拍脑袋交易」的分水岭：不可复现 = 无法验证 = 无法改进。

机器执行带来的价值：

  • 效率：一次回测几分钟，等于人工验证几百个交易日；
  • 客观：用年化收益、最大回撤、夏普比率等统计指标评价，而不是「感觉不错」；
  • 覆盖：计算机可同时盯几十个交易对，人盯不过来；
  • 纪律：速度快、执行统一、不会犹豫，没有情绪化操作。
📌 和你项目的关系

你的 SentimentFreqAI.py 里：入场 = populate_entry_trend 填 enter_long；出场 = populate_exit_trend；仓位 = 配置里的 stake_amount: 50（固定金额）；风控 = stoploss: -0.05。四件事全在这一个文件 + 一个 config 里。

2量化方法论：灵感 → 细化 → 程序 → 检验

这是全章最重要的一节 —— 策略不是拍出来的，是按这四步打磨出来的。

第一步：从一个灵感开始。灵感就是你想验证的可能盈利的方法，比如「价格跌到均线下方后会反弹」。来源：阅读、交流、自己观察。

第二步：把灵感细化成明确、可执行的策略。灵感通常是模糊的，必须细化到「什么条件、什么品种、多少量」，标准是：让任何人按你的描述在相同情形下做出相同操作。

  • 模糊版：「股价显著低于近几日平均价就买」—— 多低算显著？几日？买多少？
  • 细化一：「股价低于近 20 日均价 10% 则全仓买入；高于 10% 则清仓」
  • 细化二：补上标的范围（监测哪些品种）、排除高风险标的

第三步：把策略写成程序。用代码把规则翻译给计算机。

第四步：检验效果，两种基本方法：

  • 回测（Backtest）：用历史数据模拟执行策略。设定初始资金和时间区间，把历史行情喂给程序，输出盈亏报告。结果不好 → 改进；结果好 → 进入下一步。
  • 模拟交易（Paper Trading）：用未来的实时行情模拟执行。回测是看过去，模拟是看未来。
🔁 freqtrade 对应

回测 = freqtrade backtesting；模拟 = --dry-run。先回测、再 dry-run、最后才考虑实盘，这个顺序不能跳。

做量化只需要两样东西：数据（行情的获取、存储、清洗，freqtrade 用 freqtrade download-data 从交易所拉历史数据）和系统（能写策略、跑回测、执行交易 —— freqtrade 本身就是这样一个完整系统，这也是选它的原因：不用自己造轮子）。

3策略的基本框架：初始化 + 周期循环

几乎所有量化策略都长一个样：

  • 初始化：运行前的一次性准备 —— 选定交易品种、设置参数。
  • 周期循环：每个周期（每根 K 线/每天）重复做的事 —— 算指标、判断买卖。

类比：人做交易也符合这个框架 —— 初始化 = 你脑子里已有的交易思想；周期循环 = 每天看盘、判断、下单的动作。教程贯穿示例「每天买 100 股平安银行」框架化后就是：

初始化：选定要交易的股票为平安银行
每天循环：买 100 股

回测三要素：初始资金、起止时间、频率（天/分钟）。回测结果看收益曲线与基准对比。

freqtrade 里的对应结构：

  • 初始化 = 策略类的属性配置（timeframe、stoploss、pair_whitelist）
  • 周期循环 = 每根 K 线收盘后框架调用你的 populate_indicators → populate_entry_trend → populate_exit_trend

报错日志最后一行是错误类型（如 SyntaxError），前面是出错位置。新手三大错误：① 用了中文标点；② 拼写错误；③ 缩进不对。排错（debug）花的时间通常不低于写代码，这是正常且必须掌握的能力。

4Python 与 pandas 速查（只列量化用得上的）

快速过一遍即可，用到再回来查。

  • 变量与赋值：a = 1，变量是有名字的「盒子」，赋值即替换。
  • 数据类型：数字（int/float/bool）、字符串（交易对名 "BTC/USDT" 就是字符串）、列表、字典。
  • 列表（list）：存一组数据。pairs = ["BTC/USDT", "ETH/USDT"]；索引从 0 开始；切片 list[1:3]。
  • 字典（dict）：自定义索引。{"open": 10.0, "close": 11.0}；dict.keys() / dict.values()。
  • 条件判断：if / elif / else，可嵌套；运算符 == != > < >= <= and or not。
  • for 循环：遍历标的池的核心工具。for pair in pairs: ...
    break：跳出整个循环；continue：跳过本次、继续下一只（「跳过不符合条件的币」用 continue）。
  • 自定义函数：def 函数名(参数): + return。函数内数据通过参数进、返回值出。
  • 注释：# 开头，强烈建议写。
  • print / log：调试核心手段。freqtrade 里用 logger.info(...)。

pandas DataFrame（freqtrade 的数据核心）：二维表，行 = K 线（按时间），列 = 字段。你的策略里 dataframe 就是它。

  • 取列：dataframe['close']；
  • 滚动计算：dataframe['close'].rolling(20).mean()（20 日均线就是这么算的）；
  • 条件列：dataframe.loc[dataframe['close'] < dataframe['ma20'], 'enter_long'] = 1 —— 这就是「把买卖规则写成列」。

5数据基础：K 线 = 一行 OHLCV

每根 K 线的通用字段：open（开）、high（高）、low（低）、close（收）、volume（量），外加成交额、均价、前收等。所有技术指标、所有形态、所有预测 —— 都是从这几个数字算出来的。

很多人以为 K 线是「画出来的图」。实际上图是数据的可视化，数据才是本体。你所有策略代码操作的都是 open/high/low/close/volume 这 5 个数字 —— 画图只是为了人眼检查，机器只看数字。

两个补充常识：

  • 复权：股票因分红拆股需要复权处理；币圈没有这个问题，这是从 A 股教程迁移过来可以少学的一块。
  • 财务数据：原教程讲了财报周期、报告期口径等 —— 加密市场没有财报，这一节了解即可，跳过不亏。
🔁 freqtrade 对应

freqtrade download-data --exchange binance --pairs BTC/USDT --timeframe 1h --days 90，数据存本地，回测直接读。

数据可见性（point-in-time）—— 回测数据设计的第一原则

回测是模拟「当时」的市场。策略在 T 时刻只能使用 T 时刻已经存在的数据。任何违反这一点的代码都会让回测严重失真 —— 这就是第 7 节要展开的未来函数。

6下单语义、运行状态与风控

下单语义与订单类型（freqtrade 里不用手写，但必须懂）

四种通用下单语义：

  1. 按数量买卖：买/卖指定数量；
  2. 调仓到目标数量：高于目标卖、低于目标买；
  3. 按金额买卖：买/卖指定金额（系统按现价折算数量）；
  4. 调仓到目标市值。

订单类型：市价单按当前价立即成交（freqtrade 默认）；限价单指定价格，到了才成交。真实回测引擎会自动处理手续费、滑点（下单对成交价的不利冲击）、撮合规则 —— freqtrade 回测同样内置这些，配置里可调手续费率。

✨ freqtrade 特色

你只在策略里输出信号（enter_long=1 / exit_long=1），仓位大小由配置决定（stake_amount），下单、撤单、超时处理全部框架代劳。这比聚宽「自己调下单函数」省心很多。

运行时状态（context 概念）

任何回测/交易系统都有一个运行时上下文，存着：当前时间、持仓、持仓成本、可用资金、累计收益。策略逻辑靠读这些数据做决策。

🔁 freqtrade 对应

回测中这些由框架管理；custom_stoploss / custom_exit 等钩子函数会传入 trade 对象（含开仓价、当前利润等）和 current_time。

止损（必须掌握）

  • 定义：亏损达到一定幅度后卖出，目的是截断进一步的亏损。
  • 实现原理（通用逻辑）：
    1. 取持仓成本和现价；
    2. 算收益率 = 现价/成本 − 1；
    3. 若收益率 < 阈值（如 −10%），清仓。
  • 止盈是对称概念：盈利达到阈值后落袋。
🔁 freqtrade 对应

最简形式一行配置 stoploss = -0.10（跌 10% 自动卖）。进阶用 custom_stoploss() 写移动止损。止损是新手策略里最容易漏掉的部分，别漏。

多标的策略：标的池 + 遍历

单标的逻辑重复写 N 遍是坏味道；通用解法：用列表存标的池，for 循环遍历执行。绝大多数多标的策略（轮动、选股、再平衡）都是这个结构：

对池中每只标的：
    收益率 = 现价/成本 - 1
    若 收益率 < -10%：清仓该标的

要点：止损是逐标的计算、逐标的触发的。

🔁 freqtrade 对应

pair_whitelist 就是标的池；框架自动对每个交易对跑你的策略逻辑，你不需要自己写遍历。多标的轮动通过 max_open_trades + 排序打分实现（进阶内容）。

7回测与它的两个大敌

回测（backtesting）= 把策略放到历史数据上模拟交易，看它会赚还是亏。听起来简单，但两个「大敌」会让回测结果完全失真。

大敌 ①：未来函数（look-ahead bias）—— 最致命，且不报错

未来函数 = 策略在 t 时刻决策时，偷偷用到了 t 时刻之后才存在的信息。回测时历史数据是完整的，代码很容易「无意间」读到未来；实盘时未来不存在，于是 回测狂赚、实盘空仓或亏损。典型例子：「每天买明天涨停的股票」—— 回测里「明天」是已知的，能跑出完美曲线，现实中毫无价值。

图 1-2 · 未来函数示意 —— 这正是 crypto-trader 曾经 &-target == 1 问题的本质

未来函数最常见的三种来源（都是 shift 方向 / 窗口 / 归一化写错）：

来源错误示例为什么错
shift 方向错算指标时用了 close.shift(-1)（取「下一根」）t 时刻拿不到下一根 K 线的数据
标签窗口错用未来 24 根的价格涨跌定义今天的信号（你的 &-target）「未来涨没涨」是训练标签，不是当时可知的信息
全样本归一化用整段历史的 min/max 归一化特征，再回测归一化参数「偷看」了未来区间的统计量

排查方法：① 人工审查代码中一切与时间有关的地方（尤其注意数据接口的时间默认处理）；② 跑几天模拟交易 —— 模拟交易拿不到未来数据，有未来函数的策略往往模拟表现与回测天差地别。隐蔽情形：同一份代码模拟正常、回测却偷看了未来 —— 回测漂亮但失真，模拟跑久了会与回测相去甚远。

🧭 经验法则

回测收益极高、回撤极低、各时段都完美，感觉自己发现印钞机时 —— 大概率有未来函数。

大敌 ②：过拟合（overfitting）—— 看似聪明，实则背答案

过拟合 = 把参数调到历史数据上完美，但它记住的是噪声而不是规律，换一段行情就崩盘。参数越多越容易过拟合。经典比喻：老师不教原理，只让学生背试卷答案 —— 同一张卷子满分，换卷子就完蛋。


样本外往往越惨

图 1-3 · 过拟合的经典特征：训练期完美拟合每一个点，样本外立刻露馅

判断与应对过拟合的通用方法：

  • 样本外验证：把数据切成训练段和验证段，只在训练段调参，看验证段表现。训练段越好、验证段越差，过拟合越严重；
  • 关注参数鲁棒性：参数小幅变化，结果不该剧变；
  • 控制参数数量，多测几组参数，观察参数变化对结果的影响。
🔁 freqtrade 对应

hyperopt 是参数优化器，但必须配合样本外验证使用，否则只是「更高级的背答案」（详见步骤 ⑦）。

8回测工作流与更多陷阱

图 1-4 · 回测闭环：数据 → 模拟 → 报表 → 迭代。步骤 ③ 会详细教你读报表

三个统计陷阱（同族问题，一次认清）

陷阱一句话本质（信息泄漏类型）典型场景
未来函数用了「当时不存在」的数据信号泄漏用未来 close 算信号（你的 &-target 坑）
过拟合参数对历史完美、对未来崩盘参数泄漏反复调参直到回测好看
幸存者偏差只统计「活下来」的标的样本泄漏只回测今天还在交易所的币，忽略已下架的
⚠️ 为什么这些偏差危险：它们不报错

未来函数、过拟合、幸存者偏差有一个共同点 —— 代码正常运行、回测收益漂亮，没有任何报错提示。你只会看到「哇这个策略好赚钱」，然后把真金白银投进去。识别它们是量化最重要、最不可替代的人类技能。

模拟交易：回测与实盘之间的必经环节

回测（历史）→ 模拟交易（未来实时行情，不投真钱）→ 实盘。模拟能发现回测发现不了的问题（未来函数、撮合差异、延迟）。

🔁 freqtrade 对应

--dry-run 模式就是模拟交易，跑一段时间、对比 dry-run 与回测的一致性，再考虑小资金实盘。

9策略评价：指标、失效与取舍

回测报表怎么看？先记住这些指标（步骤 ③ 详解）：

指标含义怎么看 / 健康参考
策略收益回测期间总收益率与回测时长强相关，不利于跨策略比较
基准收益市场整体的同期收益长期跑不赢基准 ≈ 失败（不如直接拿住 BTC）
年化收益率折算成一年的收益率统一了时间标准，越大越好；但单独看无意义
最大回撤净值从峰值到谷底的最大跌幅越小越稳，<20% 较健康。直觉：你现在跟单，最坏情况就是一上来就撞上历史上跌得最惨的那一段
夏普比率每承担一单位波动换来多少超额收益风险调整后收益，>1 不错，>2 优秀
胜率赚钱的笔数占比高胜率 ≠ 赚钱（须结合盈亏比，见步骤③）
盈亏比平均盈利 ÷ 平均亏损>1.5 较健康
交易次数样本量太少则结果不可信 —— 10 年年化惊人但只交易 2 次，没人敢跟
Alpha / Beta独立于市场的收益 / 跟随市场的倍率Alpha 越大越好；年化虽负但 Alpha 为正，说明策略有超额能力，被市场部分拖累
🔁 freqtrade 对应

freqtrade backtesting 报表自带总收益、胜率、平均盈亏、回撤、夏普等；--breakdown day/week/month 还能看分时段表现。

策略失效：没有永远的印钞机

策略有时效性。警示信号：回撤创历史新高、收益曲线停滞。四类常见失效原因：

  1. 逻辑基础不再成立（制度/市场结构变了）—— 所以必须理解策略为什么有效；
  2. 资金量过大：冲击成本吞噬利润，策略有容量上限，资金应逐步加大；
  3. 同类策略太多：大家抢同一份钱，表现为想买的价格买不到；
  4. 被针对：别人监测到你的行为模式并寄生其上（先你一步买入、等你拉升后卖出）。

收益与风险的取舍

盈利能力和抗风险往往不可兼得。建议：达到基本收益能力后，极力追求低风险。理由：收益可以靠加资金放大，风险不能。例：策略 A 年化 300% 回撤 50%，策略 B 年化 30% 回撤 5% —— 给 B 十倍资金，盈利相同，但 A 永远学不会 B 的稳。

10综合实战：从灵感到完整策略（小市值轮动案例）

原教程用一个完整案例演示全流程，这里保留方法论，换成币圈语境。

① 灵感细化。灵感：「小市值的币过去一段时间表现好」。细化成文字规则：

  1. 每天选出市值最小的前 N 个币；
  2. 已持有但已不在选股列表中的，卖出；
  3. 用可用资金的 N 分之一买入每个新币。

关键一步：参数化。「10 个」不一定是唯一选择，把 N 设为可调参数。把魔法数字变成可调参数是策略细化的关键动作。

② 逐步实现。先搭「初始化+周期循环」骨架，把每条规则写成注释占位；把复杂拆成简单，逐步实现；不确定的地方用打印检查。

③ 调整改进：控制交易频率。发现每天调仓太频繁 → 引入调仓周期 period，实现「每 period 天调仓一次」。通用实现：计数器 + 取余判断（天数 % period == 0）。教程回测观察：该策略 2015–2016 表现好、2017 后平平 —— 恰好呼应灵感本身（「最近不太行了」）。这就是回测的价值：验证或证伪灵感。也说明策略有时效性。

④ 延伸思考（值得做）：

  • 参数设为多少效果好？（→ 参数优化，freqtrade 用 hyperopt）
  • 等额买入后为何各持仓价值越差越大？（涨跌不同 → 引出再平衡）
  • 加止损/止盈；
  • 选股时排除高风险/不可交易标的（A 股排除 ST/停牌/涨停；币圈对应排除流动性差、刚上线、即将退市的币）。
🔁 freqtrade 对应

这个「因子打分 + 定期轮动 + 等权配置」范式可以直接落地 —— pair_whitelist 放候选池，策略里按因子排序，配合 max_open_trades 控制持仓数。

11研究环节与成长指路

策略开发前通常先做研究：拿数据探索规律、画图验证想法。教程案例：分析同行业两只股票市值比率的波动区间 → 发现比率围绕均值波动 → 构造布林带信号（突破上轨说明前者相对高估，切换持有后者；跌破下轨反向；回中轨各半仓）→ 变成均值回归/配对交易策略。

这就是完整链条：观察统计规律 → 提出假设 → 写成策略 → 回测验证。

🔁 freqtrade 对应

download-data 拉数据 → Jupyter/脚本里用 pandas + matplotlib 分析 → 想法成立再写进策略。

  • 自学是第一能力：量化是不适合分享的行业，有价值的东西不会现成摆在那，靠「大浪淘金」式地寻找、思索。
  • 进阶四个经典方向：双均线策略（趋势跟踪）、彼得·林奇的成功投资（基本面选股）、Fama-French 三因子（因子投资）、凯利公式（仓位管理）。
  • 成长模式：有灵感 → 研究实现 → 遇到新知识缺口就补 → 成败都有新认识 → 下一个灵感，循环前进。
  • 灵感来源：论文、研报、社区、书籍，以及跨领域视角（统计、机器学习、行为金融、心理学）；直接参与市场本身就是重要灵感来源。保持批判与独立思考，警惕盲从。
  • 警惕照搬：别人公开的策略直接搬来大概率不赚钱（见第 9 节失效原因第 3 条）。

12项目映射：你在 crypto-trader 踩过的坑

SentimentFreqAI.py 曾用 &-target == 1 当入场信号。而 &-target 是 set_freqai_targets 里定义的训练标签（未来 24 根 K 线涨幅 >2% 才为 1）—— 是「答案」，不是「预测」。

  • 回测时：历史数据里带「未来」，用未来信息决策 → 回测收益失真（看起来很能赚）
  • 实盘时：没有未来数据 → 该列 NaN/0 → 永不交易

这就是「未来函数」的现实版。学完本章，你应该能一眼认出这类 Bug —— 判断标准就一句：「我决策这一刻，这个数真的已经知道了吗？」
